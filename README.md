# ☕ GetMeAChai - Patreon Clone

**GetMeAChai** is a modern crowdfunding platform inspired by Patreon, designed to empower creators to receive support from their fans seamlessly. this application offers secure authentication, and a clean user experience.

---

## ✨ Features

- 👩‍🎨 **Creator Profiles** — Creators can create and customize their profile pages to showcase content and engage supporters.
- 💸 **Fan Support** — Supporters can contribute one-time or recurring donations to creators.
- 🔐 **Secure Authentication** — Powered by NextAuth for seamless and secure user login.
- 📊 **Dashboard** — Creators can track their earnings and supporter activity.
- 📱 **Responsive Design** — Mobile-friendly UI built with Tailwind CSS.
- ⚡ **Fast & Scalable** — database powered by MongoDB.

---

## 🛠 Tech Stack
Next.js, NextAuth, MongoDB, TailwindCSS
